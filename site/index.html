nixapps

Self-hosted apps as typed Nix, not copy-pasted YAML

Application modules that render through nixidy and deploy onto an Argo CD cluster: every app a module with neutral defaults, every deployment an auditable manifest tree, every upgrade a diff.

Flagship: the LLM serving lane

  • One shared LLM server owns all models. llama-swap + llama.cpp behind a LiteLLM front door — one OpenAI-compatible endpoint, many models, loaded on demand, idle-unloaded.
  • The store IS the registry. Drop a GGUF in the right subdirectory and it is servable by name — mode from the path, context and chat template from metadata, MoE offload detected, oversized dense models refused. No hand-maintained catalog, ever.
  • Apps integrate with a key and a model name. A new LLM-consuming app requests no GPU of its own.

Status

Pre-alpha. Every listed app runs in production on a single shared-GPU cluster; the generalized modules have not been extracted yet.

Interoperating set

nixapps deploys onto the nixk3s spine; GPU apps declare the three-line contract from nixgpu and never think about the card again.
