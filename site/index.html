nixapps

A curated library of self-hosted application modules for a nixidy + Argo CD cluster

Apps as typed Nix, not copy-pasted YAML. The tenant layer of an interoperating project set: application modules that render through nixidy and deploy onto the spine shipped by nixk3s. GPU-consuming apps declare the three-line contract from nixgpu and never think about the card again.

Status: pre-alpha, first tenants pending

!

Nothing landed here yet

Every app planned for this repo runs in production on a single shared-GPU cluster, but the generalized modules for this repo's own tenants (image generation, TTS, …) have not been extracted yet.

!

The LLM serving lane graduated

It started here, was the first thing generalized, and has since moved to its own project: nixllm. LLM-consuming apps still integrate the same way — a key and a model name, no GPU of their own.

!

No invented modules or metrics

Nothing on this page claims a module, benchmark, or install path that doesn't exist. Everything under Roadmap beyond the nixllm pointer is future work, clearly marked as such.

The pitch

Every app a module

Typed Nix, not copy-pasted YAML: every app a module with neutral defaults, every deployment a rendered, auditable manifest tree, every upgrade a diff.

LLM consumers point at nixllm

Apps that need an LLM point at the nixllm front door with a key and a model name, and request no GPU of their own — the serving lane started in this repo and graduated to its own project.
